复刻宿主的媒体模块外观，但把**歌词同步与播放进度**换成自研引擎 —— 专治国内播放器（网易云音乐、酷狗音乐、QQ 音乐）在系统媒体接口下拿不到进度、歌词卡第一行的问题。

| 项 | 值 |
| --- | --- |
| 插件标识 | `com.nps.mediaenhancement` |
| 显示名称 | 媒体增强 |
| 当前版本 | **1.1.5** |
| 交付形态 | **单个 dll**（附 `plugin.json`，目录型分发包） |
| 宿主要求 | NotchPeninsula 现代插件契约（目标框架 `net10.0-windows10.0.19041.0`） |

::: tip 为什么要单独做这个插件
宿主自带的媒体模块依赖系统媒体接口（SMTC）上报的播放位置。实测网易云与酷狗的 SMTC
**能给出标题、艺术家与封面，但 `Timeline` 全为 0、且不允许 seek** —— 宿主因此拿不到进度，
歌词会一直停在第一行。本插件改用「真实进度源 + 自研歌词引擎」来解决这件事。
:::

## 一、安装

1. 把 `NpsMediaEnhancement.dll` 放进宿主 `plugins\` 目录；若用的是目录型分发包，
   把整个 `NpsMediaEnhancement\` 文件夹（含 `plugin.json`）放进去。
2. 启动宿主，进入**插件中心**，启用「媒体增强」。
3. 到 **设置 → 显示设置** 里勾选它，即可上岛。

::: warning 建议关闭宿主自带的媒体控制
两者外观相近，同时显示会在岛上并排出现两块媒体区域。
请在**宿主设置里关闭原生媒体内容**，只保留本插件。
:::

## 二、内置 PlayerCap（无需手动安装）

**PlayerCap**（Metabox-Nexus-PlayerCap，社区维护的本地服务）是本插件最高优先级的数据源。
插件会**自己把它装好并拉起**，你不需要手动下载：

| 环节 | 行为 |
| --- | --- |
| 复用已有副本 | 优先检查**下载文件夹与桌面**上是否已有 `Metabox-Nexus-PlayerCap.exe`，有就直接拿来用 |
| 自动下载 | 没有则从镜像下载到 `%LocalAppData%\NpsMediaEnhancement\PlayerCap\`，并校验文件大小（>5 MB）与 PE 头 |
| 下载源顺序 | 内置镜像（`github.boki.moe` → `ghfast.top` → `gh-proxy.com`，**直连**）→ GitHub 官方地址**经代理** → GitHub 官方地址**直连**兜底 |
| 后台运行 | 以无窗口方式启动，输出重定向到 `playercap.log`；已在运行则不重复启动 |
| 权限 | PlayerCap 需要**读取播放器进程内存**，因此必须以**管理员身份**运行 |

::: warning PlayerCap 需要管理员权限
若日志里出现权限相关失败，可在**日志窗口**里点「以管理员身份运行 PlayerCap」——
它会通过系统提权对话框重新拉起（此操作会弹出 UAC 提示，需要你确认）。
:::

::: info 如何确认 PlayerCap 已生效
打开详情页的**页 1**：点一次「重新匹配」胶囊，若按钮显示「✓ 已重取」且歌词随进度正常滚动，
说明 PlayerCap 在线且数据链路正常。
:::

## 三、歌词与进度的来源

插件按优先级依次尝试，任何一级可用就不再往下走：

| 优先级 | 来源 | 提供什么 |
| --- | --- | --- |
| ① | **PlayerCap 服务** | 真实播放位置、行边界（当前行 / 下一行起点）、封面、频谱 |
| ② | **SMTC 时间轴** | 播放位置（仅部分播放器有效） |
| ③ | **内存进度源** | 读取播放器进程内的进度 |
| ④ | **本地外推时钟** | 按播放 / 暂停状态用本地时钟推进，兜底 |

**歌词文本**走的是**插件自取链路**：网易云（落月 API 两步流程，含逐字 `yrc` 与译文）→
酷狗（官方三段链路，含 KRC 逐字）→ LRCLIB 兜底。PlayerCap 下发的歌词窗口只作取词中或失败时的兜底。

::: tip 为什么位置与歌词来自两个源
PlayerCap 的位置与「歌曲开播那一刻」同源，是准确的；而它的歌词切分与插件歌词并不完全一致
（它会把一行拆成两行）。因此插件**以 PlayerCap 的位置和行边界为基准**，
再把逐字数据从自己的歌词里按行挂载上去 —— 这样扫光与切句始终同基，不会出现「每首歌延迟都不一样」。
:::

::: details 各播放器的已知差异
- **网易云音乐**：支持逐字歌词（`yrc`）；部分冷门曲目没有逐字数据，会回退为整行扫光。
- **酷狗音乐**：系统媒体接口**不含时间轴**（业界共识），因此依赖 PlayerCap 或内存进度源才能得到进度。
- **QQ 音乐**：系统媒体接口上报的位置是**静止快照**（不随播放推进），插件用本地时钟外推补足。
- 落月歌词接口**不支持酷狗**，酷狗歌词走酷狗官方接口。
:::

## 四、收起态

灵动岛上平时显示的是：**封面 + 歌词 + 右侧频谱条**。

| 元素 | 说明 |
| --- | --- |
| **封面** | 左侧圆角封面，高度随行高自适应（20～32）。取不到封面或封面还没到时，先显示**该歌曲所在软件的图标**（等比缩到 62% 居中，不拉伸变形），封面到达后自动替换 |
| **歌词** | 垂直居中显示当前行，带逐字扫光；若有翻译或音译则显示为两行（原文 + 副行） |
| **频谱** | 右侧实时频谱条，数据优先取宿主提供的真实频谱，其次取 PlayerCap 的频谱帧 |

宽度会**自适应当前内容**（不读宿主预算），上限 760。

### 4.1 交互

| 动作 | 效果 |
| --- | --- |
| **左键单击** | 打开详情页 |
| **右键单击** | 打开详情页 |
| **鼠标悬浮在歌词区** | 歌词让位，显示**上一曲 / 播放暂停 / 下一曲**三个控件；组件宽度同步收缩 |
| **双击封面** | 启动对应的音乐软件（按会话的应用标识解析，UWP 与桌面程序都支持） |
| **右键频谱条** | 打开详情页 |

::: warning 悬浮触发范围只限歌词区
在**封面**或**频谱条**上悬浮不会显示播放控件 —— 这是有意的，避免误触。

另外，组件上**其它区域的右键不会做任何事**。原因是插件为了接管「右键频谱」，
需要声明接受右键事件，宿主的默认行为（右键展开组件、或打开控制台）随之被让出。
:::

::: tip 悬浮时宽度会收缩是正常现象
悬浮态要腾出空间给三个控件，歌词会暂时让位。插件用**自算的常态宽度矩形**判定悬浮，
而不是用宿主给出的悬浮状态 —— 否则宽度收缩后光标位置落到组件外，
会产生「一缩就闪、一闪就还原」的振荡。
:::

## 五、详情页

详情页是**一页里三个分页**，底部三个指示点切换。

### 5.1 页 1 · 播放详情

- **封面**（56×56）+ **曲名 / 歌手**
- **双行歌词**：当前行原文（逐字扫光）+ 副行（翻译优先，其次音译）
- **频谱带**：按你在页 3 选择的样子绘制
- **控制按钮**：上一曲 / 播放暂停 / 下一曲
- **「重新匹配」胶囊**（底部右侧）：重新索取当前歌曲的全部内容（元数据、封面、播放状态、
  整曲歌词、当前行与位置），用于歌词与进度错位时复位；完成后短暂显示「✓ 已重取」
- **歌词延迟补偿**（底部右侧，与页点同排）：`(−) 数值 (+)`，0.1 秒一步微调，
  **点数值本身即可归零**；非零时旁边显示强调色圆点

### 5.2 页 2 · 全部会话

- **会话列表**：每个正在播放的音乐软件一行 —— 软件图标 + 软件名 + 当前歌曲名 + 三个控制按钮
- **「查看日志」胶囊**（顶部右侧）：打开日志窗口（见下节）

### 5.3 页 3 · 外观

歌词切换动画与频谱样式的选择器，都是**带示意图标**的选项，**即点即生效并自动记住**：

| 分组 | 可选值 |
| --- | --- |
| **歌词切换动画** | 无 / 淡入 / 上滑 / 下滑 / 缩放 / 聚焦（默认「淡入」） |
| **频谱样式** | 波形 / 竖条 / 镜像 / 圆点（默认「波形」） |

::: tip 「聚焦」是什么效果
歌词从下方略微缩小、带一点模糊地滑入，随后放大到正常大小、模糊消失 —— 视线会自然被拉到新的一句上。
:::

## 六、日志窗口

从详情页**页 2** 的「查看日志」按钮打开。它是一个可拖动的独立窗口：

| 区域 | 作用 |
| --- | --- |
| 顶部 **Tab** | 在 **PlayerCap 日志** 与 **插件日志** 之间切换 |
| **刷新** | 立即重读日志 |
| **打开日志文件夹** | 在资源管理器中定位日志文件 |
| **以管理员身份运行 PlayerCap** | 通过 UAC 提权重新拉起 PlayerCap（权限不足时用） |
| **检查更新** | 立即检查 PlayerCap 是否有新版本 |
| **底部第一行：更新源 / 代理** | 两个**可直接输入**的字段，用于手填下载源与代理（见下） |

窗口的**尺寸与位置会被记住**，下次打开还是你摆的样子。

::: tip 什么时候需要手填「代理」
默认情况下，更新检查与下载**先走内置镜像直连**，只有需要访问 GitHub 官方地址时才会用到代理。
如果你的网络环境必须经代理访问 GitHub，在**代理**字段里填 `主机:端口`（也可以带 `http://` 前缀）即可。

**本地回环请求（PlayerCap 的数据链路）始终直连，不会被代理影响。**
:::

## 七、插件自更新

插件会检查自身是否有新版本（以插件市场为准）：

1. 发现新版本后**在后台静默预下载**（运行中的 exe 无法覆盖自身，所以先下载为 `.new`）；
2. 下次启动前由插件完成替换；
3. 日志窗口里会**区分**「PlayerCap 更新」与「插件更新」两类信息，不会混为一谈。

## 八、设置项

插件不提供自建的配置窗口（外观相关都在详情页页 3 点选），以下设置通过宿主设置接口持久化：

| 设置键 | 默认值 | 说明 |
| --- | --- | --- |
| `SpectrumStyle` | `0` | 频谱样式：`0` 波形 / `1` 竖条 / `2` 镜像 / `3` 圆点。一般直接在页 3 点选 |
| `LyricAnimStyle` | `1` | 歌词切换动画：`0` 无 / `1` 淡入 / `2` 上滑 / `3` 下滑 / `4` 缩放 / `5` 聚焦。一般直接在页 3 点选 |
| `LyricDelayOffset` | `0` | 歌词延迟补偿（秒），范围 `-10.0` ～ `+10.0`。一般直接在页 1 右下角调整 |
| `PlayerCapSource` | 空 | PlayerCap 的**自定义下载源**。留空用内置镜像；装不上时手动填（日志窗口底部可改） |
| `NetProxy` | 空 | 访问 GitHub 时使用的代理（`主机:端口`）。留空则直连 |

```
HKCU\SOFTWARE\NotchPeninsula\Plugin.com.nps.mediaenhancement.<设置键>
```

::: tip 卸载时会问一次
卸载本插件时，宿主会弹窗询问是否删除插件的**数据目录**（`%LocalAppData%\NpsMediaEnhancement`，存的是日志）；
与它同时被清掉的还有上面那些设置项。禁用插件或重载插件不做任何清理，只停掉轮询与 WebSocket、
结束插件自己拉起的 PlayerCap（你自己手动运行的实例不受影响）。
:::


## 九、常见问题

**Q：歌词不显示 / 只有歌词没有进度？**
按顺序检查：

1. 确认**播放器正在播放**（暂停时收起态仍显示上一句，但不会推进）；
2. 打开**日志窗口**看 PlayerCap 那一路：若提示权限不足，点「以管理员身份运行 PlayerCap」；
3. 看插件日志里有没有「换歌过渡：已忽略与当前位置不符的行」这类正常诊断行；
4. 点一次页 1 的「重新匹配」。

**Q：歌词整体超前或滞后？**
在详情页页 1 右下角用 `(−)` / `(+)` 微调（0.1 秒一步），点中间数值归零。
补偿会**同时作用于行内扫光和行切换**，所以扫光与切句保持同步。

**Q：暂停之后扫光退回行首？**
已修复：暂停会**冻结在当前行的当前进度**，不会退回开头。
（若暂停时你手动拖动进度条或换歌，则按新位置重新取行。）

**Q：歌词切换很快的歌里，扫光没跑完就切走了？**
插件会按 PlayerCap 给出的**本行真实长度**校准扫光速度，使其在本行结束前跑完；
间奏这类偏长的行不做加速，避免被拉成慢动作。

**Q：换歌时岛上还显示上一首的歌词？**
插件对新歌的行做了**位置自洽校验**（并留一个短暂的过渡窗口），
PlayerCap 在换歌期间继续推上一首的行会被忽略，不会把旧歌词贴回岛上。

**Q：频谱不动 / 暂停后消失？**
频谱来自 PlayerCap 的音频帧，暂停后不再推送新帧。插件会让最后一帧**停在原地**，不会清空。
若一直为空，检查 PlayerCap 是否在运行。

**Q：更新下载失败？**
日志会写明**当前代理 + 当前源 + 最后一次失败原因**。常见原因是网络需要代理而插件拿不到 ——
在日志窗口底部手填「代理」即可。镜像本身通常是可用的。

**Q：酷狗音乐没有歌词？**
酷狗走酷狗官方三段链路（搜索 → 取词候选 → 下载）。若拉不到词，多为网络原因或该曲目在酷狗侧没有资源；
装上 PlayerCap 后由插件统一调度会更稳。

**Q：翻译 / 音译没有显示？**
副行优先取翻译，没有翻译时取音译，两者都没有时只显示原文单行。
酷狗侧不带翻译数据，插件会**跨源补译文**（借网易云同曲的翻译，时间轴容差 500 ms 内合并）。

**Q：双击封面没有启动软件？**
插件按会话的应用标识解析可执行文件，少数以特殊方式安装的程序可能解析不到 —— 这种情况会静默失败。

**Q：文字里出现方块 / 缺字？**
插件对文本使用「宿主自定义字体优先、逐字符回退」的策略，正常不会出现方块。
若大面积出现，请检查宿主设置里的自定义字体文件是否有效。

## 十、已知边界

- **落月歌词接口不支持酷狗**，酷狗歌词必须走酷狗官方链路；
- **酷狗的系统媒体接口不含时间轴**，进度必须依赖 PlayerCap 或内存进度源；
- **PlayerCap 需要管理员权限**才能读取播放器进程内存；不装或权限不足时，
  进度精度会退到 SMTC / 内存源 / 本地外推三档；
- 部分**网易云冷门曲目没有逐字数据**，歌词会回退为整行扫光；
- 详情页尺寸**只在打开时测量一次**（宿主契约限制），因此详情页打开期间若换歌、歌词变宽，
  超长歌词会按省略号截断；关闭重开会按新宽度重新测量；
- 插件**只读** PlayerCap 的位置，所有播放控制（上一曲 / 播放暂停 / 下一曲）仍走系统媒体接口。
