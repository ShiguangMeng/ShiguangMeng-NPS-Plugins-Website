「剪贴板历史」是灵动岛插件：只要插件处于加载状态，它就持续监听系统剪贴板，把每次复制的内容记成历史，供你随时找回、重新复制。

## 一、岛上图标（常驻）

- 岛上会常驻一枚**剪贴板图标**。
- **左键单击图标**：展开 / 收起历史面板（与右键等效）。
- **右键单击图标**：展开历史面板。

::: tip 纯图标常驻
1.1.0 起岛上只显示图标本身，宽度收紧至 18px，不再占用岛上的文字宽度。
:::

## 二、历史面板

在岛上**右键**（或左键单击）剪贴板图标，即可展开历史面板：

| 区域 | 说明 |
| --- | --- |
| 标题行 | 显示当前记录条数；右侧「清空」按钮一键清空 |
| 历史列表 | 每页固定显示 4 条；更早的记录可滚动查看 |
| 底部行 | ▲ / ▼ 按钮逐行滚动；左侧显示「总条数 · 固定数」 |

### 2.1 每条记录的交互

- **图钉按钮（最左）**：固定 / 取消固定该条。已固定的条目在列表中置顶显示（实心图钉）。
- **预览文字（中间）**：显示复制时间与内容摘要。**单击整行即可把该条内容重新复制到剪贴板**，行会短暂高亮作为反馈。
- **× 按钮（最右）**：删除该条记录（已固定的条目只能通过它移除）。

### 2.2 滚动查看更早记录

- 点击底部 **▲ / ▼** 按钮逐行滚动；
- 或在列表区**按住左键上下拖动**，松手即停（不会误触发复制）；
- 也可以直接把鼠标放在列表上**滚动滚轮**翻阅历史。

::: tip 滚轮是怎么实现的
宿主的插件契约不向插件转发滚轮消息。插件在**自己进程内**装了一个低层鼠标钩子，
只在本插件详情页的屏幕矩形内接管滚轮，其余位置完全不吞。
:::

### 2.3 一键清空

- 点击标题行的「清空」按钮：**所有未固定的记录被清空，已固定的条目保留**；
- 清空完成后会弹出提示告知清空了几条、保留了几条。

## 三、监听范围

- 插件加载期间持续监听剪贴板，文本内容（`CF_UNICODETEXT`）会被完整记录；
- 非文本内容（图片、文件等）当前版本不记录；
- 与最新一条相同的内容不会重复记录，只会刷新它的时间（即**去重置顶**）；
- 插件自身「单击条目复制」产生的剪贴板变化同样走去重置顶，不会凭空多出重复条目。

## 四、数据保存与上限

- 历史记录保存在 **Windows 注册表**（随宿主设置隔离存放），重启宿主后依然保留；
- 最多保留 **50 条**：超出时自动淘汰最旧的未固定条目，**固定条目永不自动淘汰**；
- 单条内容最多记录 **5000 个字符**，超长部分截断（点击复制时复制的就是已截断的内容）。

## 五、常见问题

**Q：面板会自己收起来吗？**
鼠标离开灵动岛约 3 秒后面板自动收起；在岛内按右键也可以立即收起。

**Q：图标可以隐藏吗？**
插件的显示开关由宿主「设置 → 显示设置 → 显示内容」统一管理；勾选后插件常驻岛上。
若原生内容占满了岛体宽度，宿主可能暂时收纳该组件，空间释放后会自动恢复。

**Q：记录会包含密码吗？**
会。任何复制操作都会被记录（这是剪贴板历史工具的固有特性），
请在敏感场景使用后注意清空或删除对应条目。

**Q：复制之后卡顿或者宿主闪退？**
这是 1.0.0 的问题，**1.1.0 已修复** —— 详情见 [更新日志](/changelog/clipboard)。
插件把「读剪贴板 + 入库 + 写盘」从窗口线程搬到专用工作线程，窗口线程只做入队（微秒级返回），
并在退出时确定性收线。装 1.1.0 或更高版本即可。
