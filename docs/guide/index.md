三分钟把第一个插件装上岛。这一页讲所有插件共通的安装方式与岛上操作；具体某个插件怎么配，看左侧对应的配置教程。

## 一、先装宿主

这些插件全部运行在 **NotchPeninsula（灵动岛）** 之上，宿主是开源项目，插件本身是放在它目录里的 dll。

1. 从 [插件市场](https://nps.georgewu.top/market) 或 [宿主 GitHub 仓库](https://github.com/GEORGEWWWWU/NotchPeninsula) 获取并安装 NotchPeninsula；
2. 启动一次，确认屏幕顶部中央出现灵动岛（一条黑色胶囊）；
3. 记下程序的安装目录 —— 下面要用到它下面的 `plugins` 文件夹。

::: tip 版本要求
本站收录的插件均针对宿主的**现代插件契约**编译。个别插件有更高的最低版本要求（例如音量控制需要 1.9.3 及以上），
在每个插件的教程页顶部都标注了，安装前扫一眼即可。
:::

## 二、把插件放进去

宿主从**与主程序同级的 `plugins` 文件夹**读取插件：

```
NotchPeninsula 安装目录\
├─ NotchPeninsula.exe        ← 主程序
└─ plugins\                  ← 插件都放这里
   ├─ NpsPushBridge.dll
   ├─ Nps2FA.dll
   ├─ NpsClipboard.dll
   ├─ NpsVolumeControl.dll
   └─ NpsMinecraft.dll
```

**单文件布局**（推荐）：把 dll 直接丢进 `plugins\` 根目录即可，一个文件就是一个插件。

**子目录布局**：也可以建一个同名子目录，把 dll 和随包附带的 `plugin.json` 一起放进去。注意目录布局**必须**放在子目录里 —— 不要把 `plugin.json` 和 dll 一起丢在 `plugins\` 根目录下。

::: info 配置教程与更新日志在哪
大部分插件已经把**配置教程与更新日志写进 dll 内部**了，所以插件目录里只需要一个 dll。
装了什么版本，插件里看到的就是那个版本配套的文档 —— 旧文件顶不掉它。
:::

## 三、加载与启用

1. 重启 NotchPeninsula，或打开 **设置窗口 → 插件中心**，点一次**重新加载**；
2. 确认插件出现在列表里且已启用（插件中心里能看到名称、版本与作者）；
3. 打开 **设置 → 显示设置 → 显示内容**，勾选你要上岛的插件。

插件加载成功后，灵动岛右侧就会出现它对应的组件。

## 四、岛上怎么操作

宿主给插件的交互通道是统一的，各家插件都遵循同一套约定：

| 操作 | 一般效果 |
| --- | --- |
| **左键单击组件** | 展开该组件的**详情页**（面板向下展开，显示更完整的信息） |
| **右键单击组件** | 打开该插件的**配置窗口**，或展开一张配置摘要卡片 |
| **鼠标移开** | 详情页约 3 秒后自动收起 |
| **鼠标悬停** | 部分组件会显示更多内容（如双因素验证默认悬停才显示明文验证码） |
| **滚轮** | 仅部分插件支持（宿主契约本身不转发滚轮，支持的插件是自建了低层鼠标钩子实现的） |

::: warning 右键为什么有时只弹卡片
宿主的规则是「右键点到的组件如果没有详情页，就打开它自己的设置窗口」。
为了让右键只做插件想做的事（而不是同时弹出宿主设置窗口），多数插件会给组件配一张**配置摘要卡片** ——
右键展开的就是它，卡片上再放一个「打开完整配置」按钮。这是有意设计，不是故障。
:::

## 六、共同的设计约束

这些插件在实现上遵循几条一致的硬性约束，遇到问题时可据此判断「是不是设计如此」：

1. **零改动宿主源码**。插件只通过宿主公开的插件契约交互，宿主仓库保持逐字节未改动。
2. **不额外引入运行时依赖**。插件所需的图形能力（SkiaSharp）由宿主提供，插件自身不带第三方 dll。
3. **配置写注册表**。插件设置统一落在 `HKCU\SOFTWARE\NotchPeninsula` 下，随宿主设置一同漫游与隔离。
4. **能力边界如实告知**。宿主契约没有提供的通道（例如滚轮转发、窗口内嵌教程），插件不会假装支持。

## 七、遇到问题怎么办

1. 先看**对应插件的教程页**末尾的「常见问题」小节 —— 绝大多数现象都在那儿有解释；
2. 再打开**插件中心**看插件日志，或到宿主日志目录 `logs\plugins\<插件标识>\` 翻最近的记录；
3. 反馈问题时**附上版本号与最近几行日志**，能省掉大半来回。
