## v1.5.1 <span class="rel-date">2026-11-07</span> <span class="rel-badge">最新</span>

- <span class="rel-tag rel-opt">优化</span> **收起态频谱按自身底色取色**：详情页早已逐元素取色，收起态的频谱条仍用整岛统一色 —— 玻璃材质下文字区压在浅色窗口上时频谱会发白。现在频谱按自己那一段的背板颜色挑深 / 浅，与歌词区互不影响

## v1.5.0 <span class="rel-date">2026-11-07</span>

- <span class="rel-tag rel-add">新增</span> **实况窗（岛左侧封面气泡）**：在灵动岛左侧单独显示一个圆形气泡 —— 外圈进度弧跟随当前播放进度，内圈是当前封面（没有封面时画音符，应用图标兜底时等比缩到 62%）。播放中常驻，暂停时保留当前进度；没有歌曲或时长不可信时进度弧转为不确定态旋转。左右键点气泡展开的就是同一个媒体详情页（宿主自动复用组件详情页，不需要另做一套）
- <span class="rel-tag rel-add">新增</span> **实况窗开关**（默认关闭）：设置窗口「高级与接入」新增「显示实况窗」，拨动即注册 / 注销气泡并持久化（`LiveWindowEnabled`）。默认关闭是因为主岛已经承担歌词与频谱，左侧气泡属于可选的第二展示面
- <span class="rel-tag rel-add">新增</span> **响应宿主插件级开关**：宿主「设置 → 实况窗管理」关掉本插件的实况窗时，气泡立刻挂起、主岛内容不受影响；重新打开后继续更新进度（实现 `OnHostEnabledChanged`，并在注销时记录日志）

- <span class="rel-tag rel-add">新增</span> **独立设置窗口**：详情页右上角「设置」按钮打开（插件自建 Win32 分层窗口）。自绘标题栏支持置顶 / 最小化 / 最大化 / 关闭，双击标题栏最大化还原，Esc 关闭；窗口位置与置顶状态会被记住，下次打开原样恢复；窗口主题可自选（跟随宿主 / 浅 / 深）
- <span class="rel-tag rel-add">新增</span> **设置内容全部迁移重排**：原详情页页 2（会话列表、查看日志）与页 3（动画 / 频谱 / 律动 / 面板行为 / 译文对齐 / 延迟补偿 / 重新匹配）全部移入设置窗口，按使用顺序分六个分区：**播放与会话、歌词与扫光、频谱与律动、面板行为、日志、高级与接入**
- <span class="rel-tag rel-add">新增</span> **MSP 接入**：在宿主设置里开启「MSP 接入」（实验功能）后，插件向宿主注册四个 AI 工具 —— 当前句歌词（含译文与逐字时间）、按行号取词、整曲 LRC（纯文本 / 带字级标签）、媒体状态摘要（平台 / PlayerCap 在线 / 歌词来源 / 时间基）；设置窗口「高级与接入」显示接入状态（已启用 / 未开启 / 宿主过旧 / 注册失败）
- <span class="rel-tag rel-add">新增</span> **多行歌词**（关 / 3 行 / 5 行）：详情页显示当前句与上 / 下相邻句，换句时整块向上推移；收起态第二行同步显示下一句；与「译文对齐」双向互斥（开多行自动关译文，选译文对齐自动退回单行）
- <span class="rel-tag rel-add">新增</span> **歌词排列**（靠左 / 居中 / 靠右）：一个开关统一管当前句、相邻句与译文的横向位置
- <span class="rel-tag rel-add">新增</span> **详情页音量滑杆**：播放控制左侧新增喇叭 + 轨道 + 百分比，按**当前正在播放的音乐软件**调节音量（等价于 Windows 音量合成器里该应用那一行），点击 / 拖拽调值，点喇叭切换静音
- <span class="rel-tag rel-add">新增</span> **日志分区增强**：PlayerCap 日志与插件日志双页签；PlayerCap 更新 / 插件更新 / 重启 PlayerCap / 管理员运行四个操作按钮；「更新源」「代理」两个可直接输入的字段；Debug 日志显示开关与「清空日志」（两击确认）
- <span class="rel-tag rel-add">新增</span> **文字颜色按实际底色自适应**：读宿主亚克力背板截图（16×16 缩略），按每个元素所在位置的底色决定深字 / 浅字 —— 深色主题 + 透明材质下白色文字落在浅色背板上看不清的问题就此根治
- <span class="rel-tag rel-fix">修复</span> **音量滑杆调了没反应**：同一播放器常同时挂两路音频会话（一路空置），旧实现只改到第一路 —— 日志写「成功」而声音不动。现在按「一个应用一行」语义对该进程**所有会话逐路生效**并回读真实值；读数代表值改按「活跃 → 峰值高 → 音量大」挑选
- <span class="rel-tag rel-fix">修复</span> **PlayerCap 明明在线却拿不到歌词与频谱**：宿主自己占用了 `127.0.0.1:8765`（IPv4），PlayerCap 实际监听 IPv6 —— 插件的本地请求全部打到宿主 HTTP 服务上收到 404，却误判「在线」。现在自动探测 `[::1]` 与 `127.0.0.1`，只认协议正确的应答，命中 IPv6 时记一条警告
- <span class="rel-tag rel-fix">修复</span> **热重载后设置窗口看得见却点不动**：窗口类名是进程全局的，热重载后旧程序集的窗口类仍占着名字，鼠标消息全部掉进默认处理。现在每次加载用唯一类名注册，旧窗口在热重载时走真实关闭流程，不再留「僵尸窗口」
- <span class="rel-tag rel-fix">修复</span> **收起态歌名 / 歌词结尾不居中**：两层原因 —— 译文拿到纯空白文本时仍按双行排版（幽灵副行）；多行模式在「没有下一句」时仍给下一行预留位置。现在空文本在模型边界归一化，多行排版只在真的有下一句时启用
- <span class="rel-tag rel-fix">修复</span> **深色主题下进度条 / 播放键集体翻白**：底色不可知时按中灰估算相对亮度，浅色主题被误判成「暗底」翻成白字。现在半透明底视为「不可知」直接退回主题色，只有封面光带强覆盖时才按覆盖后颜色重判
- <span class="rel-tag rel-fix">修复</span> **底色采样整条路线重做**：最初扫屏幕像素的方案有两处致命笔误（`GetPixel` 声明在错误的 dll、反射的宿主类型名带错命名空间），失败还被静默吞掉；现改为直接读宿主渲染器的亚克力背板截图，按面板归一化坐标取值，天然兼容窗口 / DPI / 多屏
- <span class="rel-tag rel-fix">修复</span> **两处「改了设置没生效」的缓存永不失效**：计时器哨兵用 `long.MinValue`，`now − MinValue` 溢出成负数使「缓存命中」恒成立 —— 背板采样与音量轮询一次都没真正跑过。哨兵统一改 `0`
- <span class="rel-tag rel-fix">修复</span> **MSP 状态误报「宿主过旧」**：反射调用带缺省参数的方法时第 4 参未显式传 `null`，注册必然失败且状态停在「过旧」。现在逐工具捕获真实失败原因，状态档新增「注册失败 · 接口与开关都正常」
- <span class="rel-tag rel-fix">修复</span> **上一曲按钮和播放键长得一样**：四个状态图标重画（暂停双竖条 / 播放单三角 / 下一曲双右三角 / 上一曲双左三角）
- <span class="rel-tag rel-fix">修复</span> **换歌瞬间渲染线程偶发崩溃**：后台取词线程替换歌词数组与渲染线程按下标读取存在竞态，越界直接抛异常。读取前校验数组长度
- <span class="rel-tag rel-chg">调整</span> **详情页精简为单页**：移除页 2 / 页 3、底部页点与滚轮切页；「重新匹配」「延迟补偿」与全部外观设置迁入设置窗口，页面右上角新增「设置」按钮
- <span class="rel-tag rel-chg">调整</span> **原独立日志窗口移除**：全部功能并入设置窗口「日志」分区
- <span class="rel-tag rel-chg">调整</span> **多行模式下「歌词切换动画」停用**：换句固定为整块上推动画，选项置灰并附说明
- <span class="rel-tag rel-chg">调整</span> **详情页加高（196 → 240）**：为多行歌词放宽行距，底部频谱 / 进度条 / 控制按钮整体下移
- <span class="rel-tag rel-chg">调整</span> **DEBUG 日志分级**：封面跳过、几何中位差、会话重建等 10 条高频诊断行降为 DEBUG —— 文件始终全量记录，界面默认隐藏，可在日志分区开启；设置窗口全局小字同步放大

## v1.3.0 <span class="rel-date">2026-10-31</span>

- <span class="rel-tag rel-add">新增</span> **本地 LRC 歌词源**：把 `歌名 - 歌手.lrc` 放进**宿主程序目录下的 `lyrics` 文件夹**（目录不存在会自动创建）即自动优先使用。文件名归一化后打分匹配（完全等于歌名 100 / 含歌名 60 / 再含歌手 +25），**分数 ≥85 直接绕过网络与缓存**；支持普通逐行与 `[mm:ss.xx]词<mm:ss.xx>词` 增强逐字；编码依次尝试 BOM → UTF-8 → GB18030（GBK）→ Latin1 并留痕。旧的两处 `%LocalAppData%` 歌词目录仍**只读兼容**
- <span class="rel-tag rel-add">新增</span> **本地歌词按文件自己的时间轴推进**：本地文件与平台那版录音常有 0.7 秒以上的系统性差异。旧实现拿 PlayerCap 的行去匹配本地数组，一行配不上就退回平台文本 —— 文本在两只源之间跳，表现为**吞词**、每帧重扫导致卡顿、切行动画反复重启。现在只要命中本地文件，整首按文件时间轴走，PlayerCap 位置只当钟，完全跳过与平台行的文本匹配
- <span class="rel-tag rel-add">新增</span> **本地歌词自动抵消 PlayerCap 烘焙的时间平移**：PlayerCap 会按「平台报的位置与实际出声之差」把 position 整体平移（网易云默认 `-500ms`），播放器与音频链一变就成了固定残差。本地歌词分支现在把这部分抵消掉 —— 本地文件「延迟 0」即对齐，平台歌词那条路仍跟随 PlayerCap 的原意
- <span class="rel-tag rel-add">新增</span> **详情页页 1 按参考图重做**：**可点击的进度条**（两端显示已播 / 总时长，点条身跳转，播放器不支持 seek 时忽略）+ 52px 封面（带 1px 描边，深色封面上也看得清边界）+ 标题 / 歌手 / 双行歌词 / 频谱 + 上一曲 / 播放暂停 / 下一曲
- <span class="rel-tag rel-add">新增</span> **颜色律动可选跟随源**（页 3，四段：关闭 / 全局 / 人声 / 伴奏，默认关闭）：人声取 344 Hz–3.4 kHz 频段，伴奏取低频与高频的组合，全局取整帧响度；旧的「开启」设置会自动迁移为「全局」
- <span class="rel-tag rel-add">新增</span> **副行（翻译 / 音译）对齐**（页 3，四段：居左 / 居中 / 居右 / 拉伸，默认居左）：拉伸按**字间距摊满整行**而不是横向压扁字形；对齐的参考跨度是**本句歌词的实际宽度**，短句的译文不会被推到面板最右边
- <span class="rel-tag rel-add">新增</span> **切页滑动动画**：换成新页时整页从侧向滑入（230 ms、ease-out），方向按页号决定，滚轮循环翻页时取就近方向
- <span class="rel-tag rel-opt">优化</span> **律动幅度明显加大**：旧参数下包络长期贴顶（均值 0.93、帧间变化仅 0.012），看着「一直亮、几乎不动」。动态范围 26 dB → 10 / 13 / 12 dB（全局 / 人声 / 伴奏）、自动增益时间常数 15 s → 90 / 45 / 45 s、快攻 0.72，实测帧间变化提升到 0.029 ～ 0.054，静音约 2 秒归零
- <span class="rel-tag rel-chg">调整</span> **适配宿主新的 AutoWidth 插件协议**：宽度改为按宿主给的槽位额度计算（内容上限 = min(760, 额度 − 2) − 固定开销），不再写死 760；旧协议只作 `Layout` 异常时的兜底
- <span class="rel-tag rel-chg">调整</span> **收起态宽度改为即时跟随**：不再向宿主申请「宽度量化 + 变窄迟滞」—— 原来歌词每 1～2 秒换行都会重置那 600 ms 计时，收窄永远差一步，表现为「岛变短后右侧留白好几秒才收回去」。现在换句即变宽变窄（宿主自带的宽度过渡动画仍在）
- <span class="rel-tag rel-chg">调整</span> **详情页面板高 205 → 232**：页 3 增加到五组，同时让页 1 的「重新匹配」胶囊与控制按钮不再纵向贴在一起
- <span class="rel-tag rel-fix">修复</span> **右键频谱偶尔打开的是宿主设置**：内容宽按歌词实测且无上限，而组件上报宽度有 760 上限 —— 长句时频谱被画到逻辑范围之外 206 px，右键落在那一块就归了宿主。现在内容宽按「组件上限 − 固定开销」夹住，频谱 x 再夹一层；右键命中区改为「歌词末尾 → 组件右边界」，未命中会每 5 秒记一条日志
- <span class="rel-tag rel-fix">修复</span> **详情页长句歌词溢出卡片**：字号自适应（原文 13.5 → 10.5、译文 11 → 9）缩到底仍超再省略，不再越过内边距
- <span class="rel-tag rel-fix">修复</span> **歌词扫光与律动整体比人声慢**：扫光推进长度改用 PlayerCap 给出的**行时长**，并删除逐字的压缩加速（压缩只会让字提前）—— 现在扫到 100% 恰好切句；同时在插件日志里记一行「时间基：PlayerCap 按 `<播放器>-offset = -500ms` 平移 position」，延迟从此可观测
- <span class="rel-tag rel-fix">修复</span> **浅色主题下收起态进度条几乎看不见**：进度条的轨道、已完成段、头部光点、柔光四层曾写死白色，现在统一跟随宿主文字色，深浅主题都清晰

## v1.2.0 <span class="rel-date">2026-10-19</span>

- <span class="rel-tag rel-fix">修复</span> **切歌次数多了以后整块岛渲染不出内容**：宿主会永久熔断抛异常的组件。插件原本用 `try / catch` 吞异常，但异常若发生在 `Save()` 与 `Restore()` 之间，保存栈每帧多留一层，clip 与图层持续泄漏 —— 症状是「岛上什么都画不出来，宽度却照旧随内容变化」。现在所有绘制统一经护栏：吞异常后把保存栈恢复到进入时的层数，并按 10 秒限频记一条「绘制异常（组件，累计次数）」
- <span class="rel-tag rel-fix">修复</span> **详情页频谱定格不动**（收起态照常动）：PlayerCap 的音频采集助手假死后，服务端会停止向已连接的订阅者推帧，但 TCP 连接仍保持已建立 —— 阻塞读永不返回、也不触发重连，而插件把最后一帧当快照无限期沿用。现在加了音频看门狗：播放中 3 秒收不到音帧即强制重连（10 秒限频），恢复出帧时记一条「频谱已恢复」
- <span class="rel-tag rel-fix">修复</span> **每次重载或停用插件，正在播放的音乐程序跟着退出**：结束插件拉起的 PlayerCap 时用了「终止整棵进程树」，而 PlayerCap 会把播放器拉成自己的子进程，整树杀掉等于顺手结束你正在听的歌。现在只结束服务本体与同名子进程（音频助手），播放器与它的控制台窗口原地保留
- <span class="rel-tag rel-fix">修复</span> **封面取不到时日志里什么都没有**：诊断行的前置条件是「已有当前会话」，会话消失时永不落日志；取图异常又被空 `catch` 吞掉；位图已释放也看不出来。现在诊断补齐四条口子：「封面缺图」去掉前置并附会话数 / 当前会话 / 宿主封面 / PlayerCap 代数，取图失败按 12 秒限频记 HRESULT，另记「封面来源 → X」与「封面位图已失效」
- <span class="rel-tag rel-fix">修复</span> **提前释放仍在渲染的封面位图**：取图接口交出的是缓存实例本身，旧实现把退役的位图 `Dispose` 掉，渲染方随后画到的可能是已空的句柄 —— 轻则空白、重则绘制抛异常（与上面「整岛渲染失效」叠加）。现在只丢引用不释放，缓存条数仍限 12 条
- <span class="rel-tag rel-add">新增</span> **封面多级兜底接上 PlayerCap**：取图顺序变为 系统媒体接口 → PlayerCap → 宿主 → 软件图标，因此「宿主没有媒体内容、系统媒体接口也没有会话」时不再整片空白；PlayerCap 侧已抓到的封面终于有了消费方
- <span class="rel-tag rel-add">新增</span> **封面按「代数」校验**：PlayerCap 换歌时不会清掉旧图、新图约 1 秒后才到，因此只在「封面代数 = 曲目代数」时采用，否则拒绝 —— 避免上一首的封面糊到新歌上
- <span class="rel-tag rel-add">新增</span> **详情页底部的颜色律动**：取当前封面的主题色，在页面底部铺一条横向光带，透明度跟着音乐响度走 —— 安静段落完全消失，不是带底噪的常亮装饰。取色用直方图分桶（剔除灰阶与近黑近白像素）而非聚类，避免被人脸、logo 这类强对比主体带跑；明暗再按卡片底色自动适配，深色封面压在黑色实底上也会被提亮（四档底色实测对比度 3.48:1 起）
- <span class="rel-tag rel-add">新增</span> **页 3 新增「颜色律动」开关**（默认关闭）：关掉就完全不绘制，打开才跟随旋律
- <span class="rel-tag rel-add">新增</span> **详情页滚轮翻页**：上下滚动滚轮在三个分页间循环切换。宿主本身不转发滚轮（岛体平时也没有键盘焦点），插件为此自建了系统级鼠标钩子 —— 回调里只做计数，命中判定与切页交给渲染线程
- <span class="rel-tag rel-add">新增</span> **收起态进度条**：岛体最底部一条白色发光的播放进度条，宽度只覆盖歌词区、位置按当前曲目比例，亮度随节拍脉动；岛宽随歌词变化时条也跟着伸缩
- <span class="rel-tag rel-add">新增</span> **页 3 新增「面板行为」两个开关**：**忽略外部鼠标** —— 光标移出岛体、或在别处点击都不收起详情页（右键仍是关闭手势，也是唯一的关闭手势）；**永久显示** —— 详情页不再按时间自动收起
- <span class="rel-tag rel-opt">优化</span> **详情页频谱从「只有左半能动」改成全频段起伏**：PlayerCap 下发的是线性频率 + 线性幅度，音乐能量按 ~1/f 堆在最前 1/8（实测最低频段峰值 0.23，最高频段只有 0.001，相差 67 dB）；旧算法又在高频侧取桶均值并跳采，64 个显示点里只有前 17 个落在有能量的区间。现在改为对数频率轴 + 每桶取峰值 + dB 压缩与自动增益（近期峰值保持作 0 dB 参考、动态范围 72 dB、16 dB 高频倾斜补偿），定型后 64 点中有 45 点电平超过 0.05
- <span class="rel-tag rel-opt">优化</span> 频谱平滑改**快攻慢放**（上升 0.65 / 下降 0.22）：柱子弹起快、回落柔和；整体响度按近期峰值缩放（下限 0.25），安静段落不会把底噪放大成满屏，低于阈值直接判静音
- <span class="rel-tag rel-chg">调整</span> **播放中不再无限期沿用最后一帧频谱**：暂停时仍保持静止形态（这是产品要求），但播放中只给 1.5 秒宽限，超时回退到宿主频谱 —— 断流时不再假装数据还在
- <span class="rel-tag rel-chg">调整</span> **页 3 由三组排到四组**：新增两组后统一压成 26 的行高（原 30/34 的间距会把底部三个页点挤出面板），标题与选项重新对齐，页点位置不变

## v1.1.5 <span class="rel-date">2026-10-17</span>

- <span class="rel-tag rel-add">新增</span> **封面缺失时用软件图标顶上**：取不到封面或封面还没到时，先画该歌曲所在软件的图标，按 62% 等比居中而不是拉伸填满（方形标志拉伸会明显发糊）；封面随后到达自动替换
- <span class="rel-tag rel-fix">修复</span> **听多首后封面失效、只能重启恢复**：系统的媒体会话管理器长时间运行后会失效且返回空列表，旧实现只在第一次取到后一直复用。现在发现「本来有会话、突然空了」时重建，并限频每 5 秒最多一次，避免真的没在播放时反复重建
- <span class="rel-tag rel-fix">修复</span> **系统卡顿时歌词串句**：歌词更新会被渲染线程、线程池与界面线程同时调用，而它内部共用着探测数组与匹配缓存，两个线程一起进来就互相踩。现在整个更新过程串行化
- <span class="rel-tag rel-fix">修复</span> **卡顿时进度往回退**：删掉了按播放状态冻结进度的机制（播放状态每 300ms 从系统读一次，卡顿时会抖动，反而让进度走走停停）；进度恢复为纯粹的「当前位置 − 本行起点」推导，进度回退改由三层防护拦住
- <span class="rel-tag rel-fix">修复</span> 三层防护的具体口径：读数层把回退抹平窗口从 800ms 放宽到 2500ms；定位层在播放中不轻易退回上一句（真的往回拖 3 秒以上才允许）；显示层同一句内进度只增不减
- <span class="rel-tag rel-opt">优化</span> **日志改为后台落盘**：原来每条日志都在调用线程上做三次文件系统操作并持有全局锁，而调用方可能是渲染或采集线程，等于直接掉帧。现在改为入队 + 单批次后台写（32KB 一批）
- <span class="rel-tag rel-opt">优化</span> **常驻开销下调**：会话刷新 600ms → 1.2s、换歌后封面强取 8 拍 → 4 拍、取词超时 8s → 5s，诊断日志只在显示进度与真实进度偏差超过 0.05 时才输出
- <span class="rel-tag rel-opt">优化</span> 歌词逐帧复用的探测数组不再每帧新建，减少内存回收压力
- <span class="rel-tag rel-add">新增</span> **关闭与卸载时完整收尾**：停掉轮询与两条 WebSocket、结束插件自己拉起的 PlayerCap（你自己手动运行的实例不动）、日志同步落盘；卸载时把数据目录交给宿主询问是否删除，禁用与重载不触发
- <span class="rel-tag rel-chg">调整</span> PlayerCap 客户端改为可重建的单例 —— 重载插件后拿到的不再是已停止的旧实例，歌词与频谱不用重启宿主就能重新接上

## v1.1.1 – v1.1.2 <span class="rel-date">2026-10-16</span>

- <span class="rel-tag rel-fix">修复</span> **所有平台都没有歌词**：出网客户端曾强制套用系统代理，宿主进程若拿到一个只服务某个会话的代理，取词会全部失败。现改为默认直连，只有你手填了代理才启用；PlayerCap 的 HTTP 与 WebSocket 对本地回环显式禁用代理

- <span class="rel-tag rel-fix">修复</span> **「插件更新」一直提示网络不可达**：真因不是网络，而是市场响应尾部还有别的赋值语句，旧代码把等号之后的整段交给 JSON 解析必然报错，错误又被一律归类成网络不可达（该功能自 1.1.0 上线起从未成功过）。现在按括号配对取出第一个完整 JSON 值
- <span class="rel-tag rel-opt">优化</span> 解析失败时把异常类型写进提示，不再一律报成网络错误
- <span class="rel-tag rel-opt">优化</span> 封面取不到、会话未就绪时每 12 秒各记一条限流日志，便于定位
- <span class="rel-tag rel-opt">优化</span> 更新检查不再阻塞 PlayerCap 启动：先启动、后台检查、预下载下次启动替换
- <span class="rel-tag rel-chg">调整</span> 出网策略按目标分工：歌词接口直连（国内），更新检查先直连再经代理各试一次，PlayerCap 下载走「镜像直连 → GitHub 代理 → GitHub 直连」
