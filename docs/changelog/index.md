## 版本号怎么看

采用语义化版本 `主版本.次版本.修订号`：

| 位 | 什么时候 +1 | 升级风险 |
| --- | --- | --- |
| **主版本** | 出现不向后兼容的改动 | 需要留意迁移说明 |
| **次版本** | 新增功能或行为变更 | 可能影响你的使用习惯，建议读一遍 |
| **修订号** | 只含修复与优化 | 可放心升级 |

## 改动标签说明

每条改动前都有一个彩色标签，含义如下：

- <span class="rel-tag rel-add">新增</span> 新增的功能或能力
- <span class="rel-tag rel-opt">优化</span> 改善体验、性能或视觉，不改变功能边界
- <span class="rel-tag rel-fix">修复</span> 修正错误行为
- <span class="rel-tag rel-chg">调整</span> 行为或形态的变更（可能影响原有习惯）
- <span class="rel-tag rel-sec">安全</span> 与数据安全、加密与隐私相关
- <span class="rel-tag rel-del">移除</span> 删掉了原有的东西

::: tip 想快速了解某个插件的现状
直接看它日志页最上面的那个版本 —— 那是当前在用的一版。
:::
